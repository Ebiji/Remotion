# audio-reactive-3d-mv

曲(mp3)から、**リズム・ボーカル・音の強さ**を解析し、それで3D都市＋植物＋曼荼羅を動かすMVを作るスキル。
実績: **v1**(Mouth1, 143.8秒)と **v6**(Mouth2, 151.6秒)は、ユーザーが「成功例」と評価し、X(有料)に投稿した。題名は「Flowers & Towers」。

> 運用(書き出し・止まらない仕組み・エンコード・仕様)は **`references/HARNESS.md`**。
> 設計の中身(v1とv6の違い、パラメータ)は **`references/design-v1-v6.md`**。
> ユーザーに言われた失敗と好み(繰り返さない)は **`references/lessons.md`**。

## いつ使うか
- 新しい曲で、同じ思想・同じ品質のMVを作る(「曲を差し替えますので、同じ思想で」)。
- v1/v6の再書き出し、題名入れ、X/YouTube向けの作り直し。

## 一言でいうと(作り方の骨格)
1. **曲を解析**(`001/scripts/analyze_audio.py` + `analyze_voice.py`) → 30fpsのフレームごとの `kick/snare/hat/bass/mid/high/loud/inten/spec(16帯域)/beat/vox/pitch` を `analysis.<曲>.json` に保存。
2. **曲を切り替える**: `npm run song:mouth1|mouth2`(= `node scripts/use_song.mjs <曲>`)で `analysis.json` に反映。**書き出しとエンコードは `analysis.json` の曲に従う**ので、必ず確認。
3. **シーン**(`001/src/MouthMV/scene.ts`): カメラは前を向いたまま、ビル・植物が手前へ流れてくる。ビルはEQのように跳ね、空には曼荼羅の花とペイズリーの雲。
4. **描画**: Remotionでチャンク(100フレーム)に分けて書き出し。**4K(3840×2160)で描いて1080pに縮める**のが画質の決め手(v6がきれいな理由)。
5. **仕上げ**(`finish_video.mjs`): チャンク結合＋曲＋末尾の黒3秒＋題名(最後の15秒)。Xなら `std` モード。

## 守ること(ユーザーの強い希望)
- **手描きのSVG・安っぽい図形は使わない。** 全部、GLSLとジオメトリで高精細に。
- **見る人が酔わない。** 画面全体の揺れを抑える。カメラは前方固定、進む速さは控えめ。
- **色調は「鮮やか・明るい・青みのある」トーン**を保つ(v1/v6で評価された色)。
- **円錐だけの木はNG。** 植物は、種ごとに詳細に(葉脈、樹皮、花弁、垂れる蔦)。
- **「MOUTH」などの文字は画面に入れない。** 文字は、依頼された題名だけ(最後の15秒)。
- 曲の**終わりは自然に**。音のフェードアウトを足さない(曲そのものの減衰を最後まで)。

## 受け入れ基準(出す前に確認)
- 静止画を**等倍(100%)で見て**、ブロックノイズ・ギザギザがない(1コマ目はキーフレームで甘く出るので、**途中のコマ**を見る)。
- 題名が出る場面(最後の15秒)で、万華鏡の場面でも読める。
- `ffprobe`: 解像度・30fps・H.264 High・`color_space=bt709`・長さ(曲+3秒)。
- `volumedetect`: 曲の終わりまで鳴り、その後が無音(−91 dB)。
- 容量: ユーザーへの送信は**1ファイル400MiB以下**(日による。上限エラーが出たらビットレートを下げる)。
- 私(Claude)は音を**聴けない**。音の確認は数値と静止画で行い、「耳では確認していない」と正直に伝える。
