# 設計: 成功例 Tokyo Snows(冬の色版)

曲: `001/public/snow_mastered.mp3`(89.6秒、約145.5BPM)。`npm`なら `node scripts/use_song.mjs snow`。
コードは v1/v6/scat と同じ `001/src/MouthMV/`。**`scene.ts` の `IS_SN = A.SONG === 'snow'`** で分岐する(`TKLIKE` = scat と共通の東京の街・跳ねる植物)。
色は `glsl.ts` の **`SNOWPAL`**(= `SONG === 'snow'`)で、シェーダの文字列を差し替える。
完成品: `001/out/snow-tokyo-winter-title-1080p.mp4`(題名つき)/ `snow-tokyo-winter-1080p.mp4`(題名なし)。

## 構成(変えない骨格)
- 東京の街(ビルがEQのように跳ねる、蛇行する道、東京タワー/スカイツリー、看板は**文字なし**)、跳ねる街路樹。カメラは前方固定。
- **中央の花の代わりに雪の結晶**(`glsl4.ts` の `FLAKE_FRAG`): 6回対称の樹枝状結晶。枝はフラクタルに枝分かれ(`uDetail`)、中心の六角板、先端の小さな六角板。大・中・小の3枚を互い違いに回す。序盤に枝が伸び(`uGrow`)、盛り上がりで細かく。
- **雪の結晶の万華鏡**(`glsl2.ts` POSTの `flakeSD` + `scene.ts` の `SN_KAL`): 歌声のフレーズの頭(`voxOn`)で始まり**12拍(約5秒)**、前の回から20拍あける(7回)。
  1. 画面中央に結晶の輪郭が描かれる(`uDraw`)。中に街が6回対称に折り畳まれて映る。
  2. 結晶が広がる(`uFScale` 1→6)。
  3. 画面全体が曼荼羅(`uCover`)。
  4. ほどけて元の街に戻る。
  前作の「花とビルの曼荼羅」の雪版。ユーザーの希望は「**曼荼羅が画面全体に広がって、また元のシーンに戻る**」。
- **雪の物語**(`scene.ts` の `SN_FALL/SN_COVER/snMan/snMelt`): 降る→積もる(25〜40秒)→雪だるまが出来て踊る→64秒〜溶ける→70秒の大サビで吹雪と共に作り直し→81秒〜最後の雪解け。
- **雪だるま**(`snowman.ts` + `MAN_VERT/FRAG`): 3段の雪玉、炭の目・口・ボタン、人参の鼻、枝の腕(二股の指)、帽子、マフラー。下から順に固まる、キックで半分ずつ交互に跳ねる、体を揺らす、腕を振る、溶けると背が縮み裾が広がる。両側の歩道に並ぶ(大きさ1.9〜2.7)。
- **降る雪3層**(`SNOW_VERT/FRAG`): 手前=大きくぼけた雪片(12%)、中景=標準の六花(38%)、奥=粉雪(50%)。ゆっくり、風で少し揺れる。
- **終わり方**: 曲が自然に終わったあと、**無音1秒で画面が暗転**(`audio.ts` の `TAIL_FRAMES=30`、`MouthMV.tsx` の fadeOut、`finish_video.mjs` の TAIL=1)。全体 90.57秒。
- 題名「Tokyo Snows」: **開始5秒から10秒間**(`src/SnowTitle.tsx`、しっぽり明朝 Shippori Mincho、OFL)。TOKYO(字間広め)/ 氷色の細い線 / Snows。上からふわりと降りてピントが合う。

## 色彩設計(ユーザーと詰めた最終形)
- 虹色と色相の回転(hue rotation)は**使わない**。`rainbow()` を冬のパレットの帯に置き換え: 深い夜の藍 #061A33/#0A2A52、氷の青 #7FB8E6、アイスブルー #A8D8F0、雪白 #FFFFFF/#EEF6FF、シルバーグレー。赤・緑・マゼンタ・橙は**約3割**の差し色として残す。
- 建物は**濃紺のシルエット**(壁×0.3)。**室内は明るく**(明かりのついた部屋を多く、窓×1.45)。窓は白〜淡い青が基本、**3割は赤・緑・マゼンタ・橙**、1割は暖色。「寒すぎる」と言われたら色の窓を戻す。
- 路面は**濡れたアスファルト/薄い氷**: 暗くして、街路樹の金色と窓明かりがぼんやり縦に映る。雪は歩道と縁に薄く。
- 街路樹(地面の木だけ)に**シャンパンゴールド #FFD98A / ウォームホワイト #FFE9B8 のLED**を枝のラインに沿って点列で巻く。高音と拍で控えめに瞬く。暖色の面積は1割以下。**ここが作品の「肝」**。提灯は**なし**(ユーザーが不要と判断)。
- 雪の結晶は**白が基調、縁だけアイスブルー**、静かに。
- 雪だるまは**明るい雪白**(背景と区別)。マフラー・帽子のリボンは**暖かい色**(赤・橙・金)。
- 四隅は深い藍のビネット。ブルームは明るい所だけ(しきい値1.25)。
- **仕掛け: 30秒から80秒にかけて、だんだん暖かくなる**(`uWarm = sstep(30,80,t)`): 暖色の窓が1割→約6割、パレットが琥珀・ローズ・クリームへ寄る、地平線に街明かりのにじみ、雪に暖かい光、LEDが明るく、全体のグレードが暖色寄り、四隅も赤みの暗色へ。

## 画面を変えたら必ずすること
- 変える前に**同じ時刻の静止画で前後を並べて**見せる(`scripts/stills.mjs` と、完成動画から `ffmpeg -ss` で抜いたコマを `hstack`)。
- 10秒の見比べ動画: `scripts/render_segment.mjs <out> <from> <to> 1280 720` で区間だけ描き、完成品の同じ区間と `hstack`。
