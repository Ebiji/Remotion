# 設計: 成功例 v1 と v6

どちらも `001/src/MouthMV/` の同じコードで描く。**`scene.ts` の `IS_V1 = A.SONG === 'mouth1'`** で分岐する。
曲を切り替える(`npm run song:mouth1|mouth2`)と、v1/v6の構成が切り替わる。

| | **v1**(Mouth1) | **v6**(Mouth2) |
|---|---|---|
| 曲 | `public/mouth1_mastered.mp3` 143.8秒 / 4314フレーム / 約130.7BPM | `public/mouth2_mastered.mp3` 151.6秒 / 4548フレーム / 約133BPM(女性スキャット) |
| 道 | **直線** (`uRoadAmp=0`) | **蛇行** (`roadR/roadX` のワールド固定の曲線、`uRoadAmp`) |
| カメラ | 高さ `CAM_Y_V1` のキーフレーム＋**8拍ごとのショットカット**(プリセット) | 前方固定、高さ `4+6*inten`、道に沿って向きだけ追従 |
| 中央の花 | **IFSの花弁**(`HERO_VERT_V1/FRAG_V1`)、声に反応 | **空いっぱいの滑らかに歪む曼荼羅**(`HERO_VERT/FRAG`) |
| ネオン看板・光の筋 | あり(`uExtras=1`: イコライザの看板、ゴッドレイ) | なし(`uExtras=0`) |
| ドロップのフラッシュ | 固定 72秒 / 100秒 | 自動検出(`audio.ts` の `dropFlash`) |
| 声への反応 | 花・空に反応(`vox/pitch/voxOn`) | 空のペイズリー、曼荼羅の歪みが声で動く |

## 共通の骨格
- **レンダラ**: three.js 0.169 の素の `WebGLRenderer` + `EffectComposer`(RenderPass → UnrealBloom → 自作ShaderPass[色収差・万華鏡・ゴッドレイ・グレード])。SVGや2Dキャンバスは使わない。
- **世界**: カメラは z≈0 に置いたまま、ビル・植物が `uTravel` で手前に流れる(`LEN=320` でループ)。
- **ビル**(`glsl.ts`): 段(`aTier`)、窓枠・桟・窓台・柱、シェルピンスキーのカーペット模様のパネル。高さは**EQのように跳ねる**: スペクトル帯域、キックで左右交互に踏む、進行波、スネアでホップ。
- **植物**(`plants.ts` + `glsl2.ts`): 7種(大樹、枝垂れ柳、ヤシ、巨大な花、アガベ、竹、垂れる蔦)× LOD 3段(`buildSpecies(k, seed, q)`)。フレームごとにCPUでLODを選び、LOD間はディザでクロスフェード(`BANDS=[[12,82,0.001,22],[60,185,22,25],[160,4000,25,0.001]]`)。葉脈・透過光・樹皮の溝・花弁。配置は、屋上/壁/地面/垂れ蔦(モード0〜3)。
- **空**(`glsl.ts`): 星雲のfbm、Kaliの曼荼羅(`uMand`)、ペイズリーの雲(声で反応)。
- **旋律のリボン**: `RG32F` の `DataTexture`(ピッチ, 声)を道の上にたなびかせる。**幅は8192以下**(swiftshaderの上限) → 2進行単位で1サンプルに間引く。
- **粒子**: 14000。
- **万華鏡**: 16拍のうち後半8拍(= **2小節**)だけ、`inten>0.5` のとき(`Math.floor(bp/8)%2===1`)。立ち上がり・立ち下がりはなめらかに。
- **ポスト**: ブルーム、色収差、グレード(**青み**)、トーンマップ `1-exp(-col*1.25)`。虹色は `rainbow()` で彩度を高く、黄色を抑える。
- **頭と尻**: 黒からフェードイン24フレーム、最後の45フレームで黒へ(`MouthMV.tsx`)。**文字は入れない**(題名は仕上げで重ねる)。

## 音とのひも付け(`audio.ts`)
- `kick/snare/hat`: オンセットのピーク検出 → ビルの踏み、カメラの小さな押し、スネアのロール、ハイハットの火花。
- `bass/mid/high/spec(16帯域)`: ビルの高さ、ブルーム、地面。
- `inten`(曲の盛り上がり): カメラ高さ、万華鏡の条件、進む速さ。
- `travel`(進む距離): **速さは半分に抑えた** `0.5*(0.55+2.2*inten+0.9*bass+1.3*kick)`。
- `vox/pitch/voxOn`(`analyze_voice.py`): 声のある区間で、空・曼荼羅・リボンが反応。
- `beatPos`: 拍・小節。ショットカット、万華鏡の切り替えの基準。

## 画面の揺れを抑えた値(酔い対策。ユーザーの強い希望)
- カメラのy: キック×0.2。FOVのパンチ: 3.5 / 1.2。ズーム: 0.012 / 0.005。ロール(スネア): 0.008。
- 進む速さは、最初の設計の**半分**。
- 揺れを増やしたくなっても、**増やさない**。

## 色調(評価された)
- 鮮やか・明るい・**青みのあるグレード**。パステルに白飛びさせない(ブルームのしきい値、屋根の光、色のクランプで制御)。
