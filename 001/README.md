# 001

フラクタル＋花のサイケデリック動画 (Remotion, 720x1280, 15s, 30fps)

- `reference/` 参考画像と参考動画
- `src/` Remotion コンポジション
- `out/fractal-flowers.mp4` 書き出し済み動画

```
npm run studio   # プレビュー
npm run render   # out/fractal-flowers.mp4
```
